SMART REPAIR EDITION BY ALI GAMES - TEST BUILD

This test build keeps the original wetool.exe external.
The SMART READ FULL NOR button starts the ORIGINAL WETOOL with its window hidden,
then sends native top-level command 3. The WETOOL stdout is streamed into Smart Repair.
No fake READ progress is generated.

IMPORTANT:
The next native menu/READ FULL step is intentionally not guessed. If WETOOL requires
additional interactive choices after No. 3, they must be driven from the exact native
output/protocol. This build is for testing the real WETOOL process and observing its
actual output first.
